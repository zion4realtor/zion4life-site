# zion4life.faith

Zion Chen's Chinese-language outreach site: articles, videos, a daily prayer
link and a plaza of groups (读经小组 / 祷告小组 / 喂养小组). Plain HTML generated by
one script with no dependencies, hosted on Cloudflare (Workers with static
assets plus a small Worker for the groups), the same setup as zion4realtor.com.

## How it works

| What | Where |
| --- | --- |
| Site name, home page question, footer line | `content/site.json` |
| Articles / 文章 (one file per article, the file name is the URL `/read/<name>/`) | `content/articles/*.md` |
| Daily prayer / 每日祷告 (one file per day, named `YYYY-MM-DD.md`) | `content/pray/*.md` |
| Videos / 视频 | `content/videos.json` |
| Page templates | `build.mjs` |
| Styles, page script, fonts, icons | `static/` |
| Plaza `/square/`, new group form `/square/new/`, group page `/g/<id>`, admin `/admin/` | `build.mjs` (page shells) + `static/js/groups.js` |
| Group API, reminders | `src/api.js` (routed by `src/worker.js`) |
| Schedules, time zones, reading plans, calendar files | `src/schedule.js`, `src/bible.js` |
| Stored data (groups, members, check-ins, voice notes) | `src/store.js` (SQLite-backed Durable Object) |
| Emails | `src/mail.js` (Resend) |
| Cloudflare deploy settings | `wrangler.jsonc` |

`node build.mjs` writes the site to `dist/`. The Cloudflare Worker `zion4life`
is connected to this repository: on every push to `main`, Cloudflare runs
`npx wrangler deploy`, which builds `dist/` and publishes it within a minute or two.
`dist/` is served as static assets; only `/api/*` and `/g/<id>` run code.

## Common updates

- **New article:** add `content/articles/<short-name>.md`:

  ```
  ---
  title: 人生的奥秘
  summary: 一两句话，显示在列表里
  date: 2026-10-12
  ---
  正文……
  ```

  Body is simple Markdown: blank line between paragraphs, `## 小标题`,
  `- 列表`, `**重点**`, `![说明](/img/xxx.jpg)`. A scripture quote is a `>`
  block whose last line starts with `——` for the reference:

  ```
  > 神爱世人，甚至将祂的独生子赐给他们……
  > —— 约翰福音 3:16
  ```

  `sample: true` marks placeholder content (shows a 示例 tag, not indexed).
  `hidden: true` keeps an article off the site.
- **Daily prayer:** add `content/pray/2026-10-13.md` with `date` and `title`
  in the front matter, then the items. `/pray/` always shows the newest entry
  dated on or before the visitor's own date, so entries can be written ahead;
  older days stay at `/pray/<date>/` and in the 往期祷告 list.
- **Video:** add an object to `content/videos.json`: `slug` (URL), `title`,
  `speaker`, `kind` (`message` = 福音信息, `testimony` = 见证), `minutes`,
  `date`, `summary`, and `sources`, a list of places to play it from, first one
  is the default:
  - `{ "type": "youtube", "id": "VIDEO_ID", "label": "海外线路" }`
  - `{ "type": "bunny", "url": "https://iframe.mediadelivery.net/embed/LIB/ID", "label": "国内线路" }`
  - `{ "type": "iframe", "url": "<any embed URL>" }` or `{ "type": "file", "url": "<.mp4 URL>" }`

  With two or more sources the page shows 线路 buttons. Video files are never
  stored in this repository.

## Groups (小组广场)

- Anyone can start a group at `/square/new/`: type, name, what to read (a book,
  a starting chapter, chapters per session, optionally carrying on into the next
  book) or what to pray / go through, weekdays, time, length, start date, the
  time zone the time is in, who can join (on the plaza or invite-only; on the
  plaza: join directly or after the initiator approves) and the size limit.
- The group page `/g/<id>` shows the covenant (小组的约), the session in progress
  or the next one in the visitor's own time zone, the join form (name + email or
  phone + the covenant checkbox), and for members: check-in (打卡) with notes and
  an optional voice note (up to 2 minutes), the calendar file (one event per
  session with a 10-minute alarm), the invite link, their personal link and the
  check-in records. The initiator approves applications, removes members,
  updates the material of prayer / feeding groups and can end the group.
- Privacy: contacts are used only for reminders and never sent to any page, not
  even the initiator's. Check-in notes and member names are visible to members
  only. Sign-in has no passwords: a token kept in the browser (hash stored), and
  a personal link in every email that signs that phone in.
- Reminders: every 5 minutes the cron trigger emails members with email
  reminders on, 5–20 minutes before each session, once per session. Phone
  numbers get no SMS yet; the calendar file covers phone reminders.
- Settings (Cloudflare → Workers & Pages → zion4life → Settings → Variables and
  Secrets; `keep_vars` keeps them across deploys):
  - `RESEND_API_KEY` (Secret) and `FROM_EMAIL_ADDRESS`, e.g.
    `Zion4Life <hello@mail.zion4life.faith>` on a domain verified in Resend.
    Without them emails are skipped and everything else works.
  - `ADMIN_KEY` (Secret): the password for `/admin/`, where Zion takes groups
    off the plaza.
- Bible links: set `BIBLE_LINK` in `src/bible.js` once Zion sends the Recovery
  Version address; until then readings show without a link.

## Mainland China

- Load nothing from Google, YouTube thumbnails or public CDNs on page load
  (`tests/build.test.js` checks). Fonts are self-hosted: Noto Serif SC 600 split
  by unicode-range in `static/fonts/serif/` (SIL OFL), body text uses the
  phone's system font.
- Videos load only when tapped, so a blocked player never slows the page.
- Keep a neutral backup domain ready to point at the same Worker if the main
  domain is blocked.

## Local preview and tests

```
node build.mjs && node scripts/serve.mjs   # http://localhost:3000 (static pages only)
npx wrangler dev                           # everything, including groups, on the Workers runtime
node --test
```
