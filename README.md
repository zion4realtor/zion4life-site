# zion4life.faith

Zion Chen's Chinese-language outreach site: articles, videos, a daily prayer
link and (phase 2) reading groups. Plain HTML generated by one script with no
dependencies, hosted on Cloudflare (Workers with static assets), the same setup
as zion4realtor.com.

## How it works

| What | Where |
| --- | --- |
| Site name, home page question, footer line | `content/site.json` |
| Articles / 文章 (one file per article, the file name is the URL `/read/<name>/`) | `content/articles/*.md` |
| Daily prayer / 每日祷告 (one file per day, named `YYYY-MM-DD.md`) | `content/pray/*.md` |
| Videos / 视频 | `content/videos.json` |
| Page templates | `build.mjs` |
| Styles, page script, fonts, icons | `static/` |
| Cloudflare deploy settings | `wrangler.jsonc` |

`node build.mjs` writes the site to `dist/`. The Cloudflare Worker `zion4life`
is connected to this repository: on every push to `main`, Cloudflare runs
`npx wrangler deploy`, which builds `dist/` and publishes it within a minute or two.

## Common updates

- **New article:** add `content/articles/<short-name>.md`:

  ```
  ---
  title: 人生的奥秘
  summary: 一两句话，显示在列表里
  date: 2026-10-12
  ---
  正文……
  ```

  Body is simple Markdown: blank line between paragraphs, `## 小标题`,
  `- 列表`, `**重点**`, `![说明](/img/xxx.jpg)`. A scripture quote is a `>`
  block whose last line starts with `——` for the reference:

  ```
  > 神爱世人，甚至将祂的独生子赐给他们……
  > —— 约翰福音 3:16
  ```

  `sample: true` marks placeholder content (shows a 示例 tag, not indexed).
  `hidden: true` keeps an article off the site.
- **Daily prayer:** add `content/pray/2026-10-13.md` with `date` and `title`
  in the front matter, then the items. `/pray/` always shows the newest entry
  dated on or before the visitor's own date, so entries can be written ahead;
  older days stay at `/pray/<date>/` and in the 往期祷告 list.
- **Video:** add an object to `content/videos.json`: `slug` (URL), `title`,
  `speaker`, `kind` (`message` = 福音信息, `testimony` = 见证), `minutes`,
  `date`, `summary`, and `sources`, a list of places to play it from, first one
  is the default:
  - `{ "type": "youtube", "id": "VIDEO_ID", "label": "海外线路" }`
  - `{ "type": "bunny", "url": "https://iframe.mediadelivery.net/embed/LIB/ID", "label": "国内线路" }`
  - `{ "type": "iframe", "url": "<any embed URL>" }` or `{ "type": "file", "url": "<.mp4 URL>" }`

  With two or more sources the page shows 线路 buttons. Video files are never
  stored in this repository.

## Mainland China

- Load nothing from Google, YouTube thumbnails or public CDNs on page load
  (`tests/build.test.js` checks). Fonts are self-hosted: Noto Serif SC 600 split
  by unicode-range in `static/fonts/serif/` (SIL OFL), body text uses the
  phone's system font.
- Videos load only when tapped, so a blocked player never slows the page.
- Keep a neutral backup domain ready to point at the same Worker if the main
  domain is blocked.

## Local preview and tests

```
node build.mjs && node scripts/serve.mjs   # http://localhost:3000
node --test
```
